Пересборка Pocket 0.1.21 из объединённых веток: настраиваемые помощники, статусы доставки, ограниченные фоновые проверки, сохранение экрана при повороте, удаление сообщений и получение ответов без исходного чата.

Исправлена JVM-проверка реестра помощников для Oracle JDK: ключ Android Keystore задаётся тестовым окружением, а шифрование AES-GCM выполняется настоящим JCE. Код хранения токенов приложения не изменён. Проверка на физическом телефоне не выполнялась.
