# Настройка помощников

Версия 0.1.16 завершает карточку отменённого владельцем запроса и блокирует
его повторную отправку. Запоздалое старое подтверждение Codex не восстанавливает
такой запрос. С мостом 0.2.4 ожидание Codex показывается отдельно от выполнения;
превышение срока ожидания требует проверки получателя и не доказывает ошибку.

В настройках приложения добавьте помощника: имя, адрес моста, токен.
Можно добавить любое число профилей в пределах 64 сохранённых записей.
Для частного LAN включите соответствующий флаг; HTTP разрешён только для частных
адресов. Проверка подключения получает и закрепляет идентификатор помощника.

Выберите профиль в разговоре. Запрос отправляется по его адресу с его токеном.
`Передай Кодексу: ...` / `Спроси Кодекс: ...` передаются Codex именно этого
помощника. Требуется настроенный локальный маршрут на стороне моста.

Список моделей приходит от выбранного помощника. В настройках можно изменить
подписи моделей. Выбор сохраняется для профиля и разговора; исходный ID модели
проверяет сервер. Списки других помощников не подставляются автоматически.

Изменение подключения создаёт новую запись. Уже отправленные запросы продолжают
получать ответы со старого адреса с исходными реквизитами. Удаление профиля
сохраняет историю и такие подключения; новые сообщения требуют активного профиля.
Существующие настройки Гонца/Домового переносятся автоматически.

Токены зашифрованы Android Keystore. Публичный APK не содержит личных настроек.
Общий протокол и схема: [BRIDGE_ROUTING_RU.md](https://github.com/OLDest/gonets-bridge/blob/codex/codex-peer-routing/docs/BRIDGE_ROUTING_RU.md).

Проверки: `verify-android.py`, `verify-assistant-registry.py`,
`verify-delivery-flow.py`, `verify-model-picker.py`, `verify-notifications.py`,
`verify-pending-notifications.py`. JVM-проверки не заменяют проверку на телефоне.

Для подписи на другом компьютере `build.py --unsigned` готовит только публичный
выровненный APK. Подпишите его прежним release-ключом, сравните сертификат с
прошлым публичным APK и затем подготовьте release-метаданные. Приватный ключ
не требуется переносить на машину сборки.
