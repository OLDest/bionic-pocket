# История сообщений: Pocket 0.1.19

- У сообщения нажмите **⋮ → Выбрать** или удерживайте его заголовок/текст. Отмечайте сообщения флажками. Верхняя панель показывает количество; доступны «Все» и «Удалить». Для одного сообщения можно выбрать **⋮ → Удалить** сразу. Удаление требует подтверждения.
- **☰ → ⋮ у чата → Очистить сообщения** очищает его историю, сохраняя сам чат, помощника, модель, подключение и черновик. Эта команда также есть в настройках текущего чата. Полное удаление чата остаётся отдельным действием.
- «Копировать» сохранено в меню сообщения и в панели выбора одного сообщения. Выбор завершается при уходе из приложения или переключении чата. Обычный поворот экрана сохраняет выбор вместе с существующей Activity.

Удаление относится к локальной истории телефона. Уже отправленные задачи на ПК не отменяются, данные моста и файлы вложений этим действием не удаляются. Для удалённых ответов сохраняются локальные маркеры ID: received/in_progress/completed из API не восстановят удалённую карточку. Очистка дополнительно скрывает старую ленту до момента очистки; новые запросы продолжают работать. Маркеры привязаны к конкретному чату и сохраняются с ним. Журнал защиты от повторных уведомлений не сбрасывается.

Проверки `verify-chat-history.py` исполняют реальный код удаления и слияния ответов переднего/фонового режимов: выборочное удаление, порядок оставшихся сообщений, старые дубликаты, сохранение маркеров, поздние ответы, независимость чатов, новые запросы после очистки и прекращение фонового опроса пустого чата. Также выполняются проверки доставки, уведомлений, фоновых ограничений, lifecycle и Android-сборка. Android-интерфейс на физическом телефоне не проверен: подключённого ADB-устройства нет.
