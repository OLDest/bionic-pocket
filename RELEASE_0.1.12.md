Выбор модели и ожидание ответов

- Для каждого помощника появился выбор модели из списка, предоставленного его API. Выбор сохраняется в разговоре и фиксируется в отправленном запросе: переключение модели не меняет запросы, ожидающие ответа.
- Если помощник не предоставляет список моделей, доступен вариант по умолчанию. Недоступная выбранная модель не подменяется молча.
- HTTP 429, ошибки сервера и таймауты показываются отдельно от обрыва соединения. Сохранённый ID запроса используется для повторной проверки доставки.
- Постоянное уведомление фонового ожидания снимается, когда приложение открыто или больше нет ожидаемых ответов. Ожидание активных запросов и ответов Codex сохраняется; плановая фоновая проверка остаётся.

Проверено: JVM-проверки фактических методов доставки, возобновления загрузки вложений, идентификаторов запросов, выбора модели, карточек Codex, уведомлений и дедупликации; компиляция Android. Публичный APK не содержит личного токена. Обновление подписано прежним ключом.
